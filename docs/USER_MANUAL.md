# Manual de Usuario (Estándar)

Esta guía cubre las funcionalidades básicas incluidas en el sistema base Alquimia 2.0.

## Inicio de Sesión
El sistema cuenta con un módulo de autenticación seguro.
- Ingrese su **Username** o **Email**.
- Ingrese su **Contraseña**.

> [!NOTE]
> El usuario administrador por defecto (creado con `seed_default_user`) suele tener credenciales estándar definidas en el archivo `.env` o en el seeder.

## Gestión de Áreas
Dependiendo de su Rol, tendrá acceso a diferentes menús.
- **Admin**: Acceso total al sistema.
- **User**: Acceso restringido a módulos básicos.

## Funciones Comunes

### Cerrar Sesión
Siempre cierre su sesión al terminar de usar el sistema para prevenir accesos no autorizados.

### Recuperación de Accesos
Si no puede ingresar, contacte al administrador de base de datos o utilice el comando de reseteo (si ha sido implementado por el desarrollador).
